# RoleRelay project rules

- FSD I is frontend-only: React, Vite, JavaScript, plain CSS, Fetch, and localStorage.
- Do not add a backend, database, authentication, AI services, or state framework.
- Implement only the requested milestone. Foundation routes are not completed features.
- Use genuine sourced events; label curated and demonstration data honestly.
- Team plans are browser-local. Do not simulate invitations or shared accounts.
- Keep components focused and calculations pure. Avoid duplicated business rules.
- Catch fetch and storage failures; never silently replace damaged data or fabricate fallback records.
- Feature owners supply domain validation when using the storage helpers.
- Coordinate changes to App.jsx, styles.css, package files, and storage.js.
- Each contributor writes, understands, and commits their own work on a feature branch.
- Require peer-reviewed pull requests. Never impersonate contributors or fabricate history.
- Run npm run lint, npm test, and npm run build before proposing a merge.
- Do not commit or push unless explicitly requested.
